# Drum Kit 🥁

An interactive Drum Kit web application built with HTML, CSS, and JavaScript.

## Features

* Play drum sounds using mouse clicks.
* Play drum sounds using keyboard keys (`W`, `A`, `S`, `D`, `J`, `K`, `L`).
* Real-time audio playback using JavaScript.
* Button press animations for better user interaction.
* Responsive and visually appealing drum interface.

## Technologies Used

* HTML5
* CSS3
* JavaScript (DOM Manipulation & Event Handling)

## How It Works

Each drum button is mapped to a specific drum sound. Users can either:

1. Click on a drum button, or
2. Press the corresponding keyboard key.

JavaScript listens for both click and keyboard events, plays the associated sound, and triggers a brief button animation to simulate a drum hit.
